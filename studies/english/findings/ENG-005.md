# ENG-005: Script identity and visual similarity must not determine PERSON membership

## Question and scope

Which assumptions about name form or reference could reject valid mentions or create false positives? Scope follows the [dossier overview](../overview.md); constructed robustness cases are not claims about normal usage.

## Observation

Unicode assigns script properties to characters and defines separate confusable-detection mechanisms. These describe representation, not whether text names a person. See [ENG-S008](../sources.md#eng-s008), UAX #24 sections 2–3, and [ENG-S009](../sources.md#eng-s009), UTS #39 sections 4–5. Applying an identifier restriction directly as a PERSON rejection rule is an engineering inference that these sources do not validate.

Observation confidence: medium overall, because source-backed distinctions are narrower than the proposed NER application.

## NER hypothesis

Preserving raw text while using script context as a feature will retain more reviewed cross-script mentions than a Latin-only gate, without increasing matched-negative errors. Confusable folding is a separate experiment, not part of this prediction.

## Evidence handoff

Pair quoted names and ordinary quoted words; separate accented Latin, natural cross-script mentions and artificial substitutions. The ordinary-word controls must have equivalent carrier context. Review label policy for intentionally corrupted text before scoring.

Disposition: ready-for-owner-review local proposal; no downstream issue created.

## Evaluation handoff

Compare candidate recall and exact spans with and without a script eligibility gate, holding model and evidence fixed. Separately test confusable folding against distinct-string controls; reject it if it merges distinctions required by the target contract. No measurement yet; evaluation waits for reviewed evidence and its offset contract.

## Implementation options

Retain the existing approach as a baseline. Test the scoped capability above before adding language-wide hard rules. See the [decision brief](../decision-brief.md); implementation belongs to `fastner`, not this repository.

## Limitations and review

Character standards establish representation facts strongly; the NER examples and design inference have no independent linguistic review. No code-switching frequency or detection gain is claimed.
