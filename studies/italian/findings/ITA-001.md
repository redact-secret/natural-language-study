# ITA-001: Elided articles and prepositions can touch a name without belonging to it, while D'/Dell' can be name-internal

## Question and scope

Can an apostrophe-final item before a capitalized word be classified as external grammar (dell'Anna as 'of Anna') or as the start of a surname (Dell'Orso, D'Annunzio-style)? Scope: contemporary standard written Italian (it-IT), Latin script, PERSON, edited prose. Exclusions: dialect, historical spelling, regional use of an article before first names, speech.

## Observation

Italian marks vowel elision with an apostrophe for singular definite articles and the matching articulated prepositions (l'ombrello, nell'epica) ([ITA-S004](../sources.md#ita-s004), whole entry). The same visible shape occurs inside surnames: Caffarelli's Crusca answer gives D'Eredità as a surname whose particle is capitalized as part of the name ([ITA-S001](../sources.md#ita-s001), Grafia). The UD Italian guideline for names shows `Marcello Dell' Utri` with `Dell'` as a token inside a flat name structure ([ITA-S013](../sources.md#ita-s013)), so the treebank treats a Dell' token as name-internal there. UD also splits articulated prepositions into multiword tokens ([ITA-S012](../sources.md#ita-s012), Tokenization); that is a syntactic word segmentation and not a PERSON boundary. Elision source and name source are independent publishers (Treccani, Crusca, UD), but no source compares the two roles directly, so the contrast is the author's synthesis. Confidence medium: the grammar rule is well supported, the role contrast is inferred.

## NER hypothesis

A model that treats a leading capitalized-after-apostrophe item as external grammar will omit the particle of surnames such as example-02 and example-05, while one that always joins it will absorb external dell' in example-01. Context features (preceding noun, a determiner or verb, a preceding given name) should reduce both errors compared with a fixed rule. Refuted if a fixed rule matches or beats the contextual one on matched cases.

## Evidence handoff

Positive: given name followed by Dell'/D'/Dall' surname. Hard negatives: noun + dell'/d' + given name or common noun, article before first names, place names such as L'Aquila. Variation axes: U+0027 versus U+2019, space after the apostrophe, ALL-CAPS, sentence start. Destination: `ner-evidence`; no issue opened. Proposal is ready for owner review after Italian-language review of examples.

## Evaluation handoff

Proposed slice `ita-elision-role`: matched pairs differing in the preceding context only. Question: does each approach omit internal particles or include external ones? Failure condition: external inclusion rises while internal omission does not fall. Destination: `ner-eval`; a proposed slice name, not a registered dimension. No measurement exists.

## Implementation options

Options: (a) keep apostrophe tokens whole and let the tagger decide; (b) emit alternative start candidates after the apostrophe; (c) no change as baseline. Tradeoff: option (b) raises candidate count; it does not decide inclusion. Destination: `fastner`; options only, no code inspected or changed for this finding.

## Limitations and review
