# KOR-003: Hangul normalization must preserve the original text coordinates

## Question and scope

Can equivalent Hangul representations be recognized consistently while retaining original coordinates? Scope: Contemporary South Korean standard written Korean; Hang, Hani, Latn scripts, general correspondence/narrative, PERSON. Original and constructed robustness inputs are distinguished; see [dossier scope](../overview.md).

## Observation

Unicode defines canonical equivalence between precomposed Hangul syllables and conjoining jamo sequences [KOR-S002](../sources.md#kor-s002). NFC/NFD can change code-point length without changing the represented name. This is encoding equivalence, not romanization or Hanja identity resolution.

Confidence: **high for the narrowly stated observation**, based on the cited publisher guidance or standard. This confidence does not apply to the NER hypothesis or example interpretations.

## NER hypothesis

Canonical normalization with reversible coordinate mapping will improve equivalent-string consistency versus raw-only lookup without corrupting returned spans. Reject if gains are absent or offset by matched-negative errors.

## Evidence handoff

Pair NFC/NFD names and common nouns; keep original strings and record transformations; add mixed Latin/Hangul only as a separately reviewed extension. Destination: `ner-evidence`; **deferred pending language/example and annotation-policy review**. No downstream issue has been opened.

## Implementation options

Compare normalized feature lookup with raw baseline; retain source text and explicit mapping. Never assume normalized offsets equal source offsets. Destination: `fastner`; proposed experiments only, deferred until evidence review.
